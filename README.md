# 描いてバトン

絵だけでつなぐ、ゆるっと伝言ゲーム。3〜8人で遊べるWebアプリです。

## 遊び方
1. 名前を登録して、難易度と制限時間を選ぶ
2. 1人目だけにお題が出るので、絵で描く
3. 2人目以降は前の人の絵を見て絵を描き、「これはなんだとおもう？」を文字で予想する
4. 全員終わったら、お題・絵・予想を順番に公開

## 機能
- オフラインモード（1台のスマホを回して遊ぶ）
- お題100個（かんたん／ふつう／むずかしい）とオリジナルお題
- 制限時間 30秒／60秒
- 結果の画像保存、LINE共有

## 使い方
`index.html` をブラウザで開くだけで動きます（ビルド不要・単一ファイル）。
GitHub Pages で公開する場合は、Settings → Pages で main ブランチのルートを選択してください。
